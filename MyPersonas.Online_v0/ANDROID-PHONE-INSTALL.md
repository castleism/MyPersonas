# Install the websites and owner apps on Android

A cloud agent cannot tap your phone. Use Chrome on the device after this source is live on HTTPS.

## 1. Install the AliaSpaces website as an app

1. Open `https://mypersonas.online/` in **Chrome**.
2. Tap **⋮** → **Install app** or **Add to Home screen**.
3. Confirm. The home-screen icon opens the public site as a standalone browser app.
4. After sign-in, Owner home is `#/owner`. Sites & apps is `#/sites`.

## 2. Install the Owner check list as its own app

1. Open `https://mypersonas.online/owner-phone.html` in Chrome.
2. Tap **⋮** → **Install app** or **Add to Home screen**.
3. Confirm. The **Owner check** icon lists every documented website and in-development app.

Samsung Internet: menu → **Add page to** → **Home screen**.

## 3. Other sites to add if you want separate icons

These are already on the Owner check list. Add them from their own origins if you want extra icons:

- Noo Youniverse: `https://nooyouniverse.com/`
- Being Tea Co.: `https://beingteaco.com/` (Akiko is the public host)
- Castleborn: `https://castleborn.online`

## 4. Not phone-installable from this repo

- **Workroom Bridge** — desktop Electron scaffold only.
- **Gemini research console** — local repo file, not in the Pages artifact.

Do not publish, schedule, or add shop links from these install steps.
