# 50-hour portfolio command board

Window: Friday 2026-08-14 through Monday morning, Alaska time.

This board compresses decision-making and validation, not external review timelines. Its Monday target is a smaller set of secure, verified, revenue-capable surfaces—not a false claim that every account, site, native app, social integration, and payout system is complete.

## Operating rules

- Security containment outranks feature count.
- Work in four lanes, with one writer per repository/branch: containment, MyPersonas platform, revenue, and content/distribution.
- Run research/review in parallel; serialize writes and releases.
- A task is complete only when its stated evidence exists.
- Keep global publishing and AI-spend stops on unless a named controlled test requires a temporary resume.
- Default paid spend is $0. No auto-recharge. Trial credits are used only after a fixed redacted benchmark.

## Monday scorecard

Record each item as one of: `local`, `tested locally`, `pushed`, `deployed`, `verified live`, `revenue-ready`, `blocked`, or `not started`.

Minimum credible Monday win:

- all known P0 public leaks closed and re-probed;
- CI green and production deployments gated;
- MyPersonas recurring publisher still safely dormant unless every activation gate is proven;
- one low-value model integration proven end-to-end with AAL2, Vault, host restriction, budget, revocation, and erasure;
- PrintMason hidden product flow tested or honestly blocked on owner/business verification;
- Being Tea email consent flow tested;
- Fix My Frozen PC TLS and live intake state known;
- five evidence-led persona packages ready for owner approval, with zero fabricated metrics and no unapproved posting;
- exact trial spend, remaining credits/expiry, and unused-key revocation list recorded.

## Stop conditions

Stop the affected lane immediately for a credential exposure, unexpected charge, provider write beyond scope, ambiguous publish/payment outcome, failed erasure/revocation, source/live mismatch, broken TLS, P0 privacy leak, CI bypass, or missing audit record. Preserve evidence, disable the narrow key/automation, and reconcile before retrying.
