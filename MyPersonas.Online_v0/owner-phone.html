Install on this Android phone

Chrome can put AliaSpaces and this check list on your home screen. A cloud agent cannot tap your phone for you — use the button if Chrome offers it, or follow the steps.

  1. Stay on this HTTPS page in Chrome (not a downloaded file).
  2. Tap the menu ⋮ → Install app or Add to Home screen.
  3. Confirm. Open the new Owner check icon.
  4. From AliaSpaces home, repeat the same steps to install the main website app.
