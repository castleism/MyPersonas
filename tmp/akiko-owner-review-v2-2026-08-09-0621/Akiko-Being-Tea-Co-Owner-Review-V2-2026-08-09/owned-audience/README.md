## What the form records

The PDF contains ten interactive text fields:

1. date;
2. tea / product;
3. amount;
4. water;
5. temperature;
6. time;
7. vessel;
8. one thing noticed;
9. one variable to change next; and
10. an optional source / package note.

It follows the method already proposed in `PROFILE-PINNED-AND-OWNED-AUDIENCE-COPY.md`: keep every variable steady except the one being tested, then record one honest observation.
