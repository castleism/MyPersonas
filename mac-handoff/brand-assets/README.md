# Portfolio vector identities

Twelve original editable geometric marks, generated reproducibly by polish-brand-assets.py. index.html is the review gallery; individual SVGs are editable source. No raster artwork or stock logo was generated in this pass.

Android resources include full-size legacy vector launchers, adaptive icons for Android 8+, monochrome icons for supported themed launchers on Android 13+, and matching decorative welcome illustrations. The same warm paper/accent palette follows the existing in-app artwork. The native guide excludes decorative art from screen-reader announcements.

This does not replace existing approved persona imagery or create video/photo assets. iOS launchers need proper raster asset catalogs generated on the Mac from these vectors and then verified in the iOS build. Store marketing screenshots need to show real implemented screens, not fabricated functionality.
