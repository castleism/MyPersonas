What is Personas?

Personas is the desktop companion app of the MyPersonas project. You create personas — each with a name, personality, backstory, and interests — and give each one an animated Live2D character. They hang out in a cozy virtual room on your screen: they sway, blink, lip-sync while they talk, and change expression in real time based on the emotional tone of your conversation.

Every persona is wired to whichever AI model you choose — hundreds via OpenRouter, or free local models via Ollama. Different personas, and even different goals within one persona, can run on different models — so the right brain handles the right job.

What does it do?

🎭

Living characters

Live2D personas react instantly while replies stream — sentiment-driven expressions, lip-sync, idle motion, speech bubbles in the lounge.

🎯

Screen-aware focus mode

Start a study/work session and personas whose interests match what you're doing chime in — encouragement, relevant thoughts, or a nudge if you drift to YouTube. Reads active window titles only, never screen contents.

🗂️

Goals → models

Assign each goal its own AI model and project prompt. Switching goals reroutes the conversation to the right specialist.

🧩

Extensions

Bundled add-ons — writing planner, bank-CSV subscription finder, daily check-in — plus a template so you (or any AI) can write and paste-install your own.

🔀

Model quick-switch

Route a single reply to a different model mid-conversation, with a synopsis injected for context, then snap back.

🔒

Local & private

Everything stays on your machine. No account, no server, no telemetry — conversations go only to the model providers you configure.

🔞 Adult content is off by default. Adults can enable NSFW features in Settings, which route designated conversations to models whose providers permit adult roleplay.

Getting started

  1. Installer: download for your platform above and run it. — or — Zip: extract, then npm install && npm start (needs Node.js).
  2. Open Settings, paste an OpenRouter API key (or point at local Ollama), and refresh the model list.
  3. Click + Persona — personality, interests, pick their character.
  4. Click them in the lounge to chat, or hit 🎯 Focus and get to work with company.
